# Лабораторная работа по математической статистике (Лаборатория 4)

## Описание проекта

В этом репозитории содержится решение лабораторной работы №4 по курсу "Математическая статистика". Работа включает два основных задания:

1. **Линейная регрессия на данных о продажах автомобилей**  
   Анализ зависимости цены автомобиля от расхода топлива в городе и на шоссе, а также от мощности двигателя. Построена линейная модель, проведена проверка статистических гипотез, оценены коэффициенты модели и выполнена диагностика остатков.

2. **Однофакторный дисперсионный анализ (ANOVA) на данных об ирисах**  
   Проверена гипотеза о равенстве средних суммарной площади чашелистика и лепестка для разных подвидов ириса с помощью классического дисперсионного анализа.

## Структура репозитория

- `task1.py` — код для выполнения задания 1 (линейная регрессия)
- `task2.py` — код для выполнения задания 2 (ANOVA)
- `cars93.csv` — исходные данные по продажам автомобилей
- `iris.csv` — данные об ирисах
- `report.tex` — LaTeX файл с полным отчётом по лабораторной работе
- `car_price_fit.png` — график реальных и предсказанных цен из задания 1
- `output_task1.png` — изображение с выводом по заданию 1 (опционально)
- `boxplot_iris.png` — график распределения площади по подвиду ириса (для задания 2, если есть)

## Как запустить

1. Установите необходимые библиотеки:

```bash
pip install pandas numpy statsmodels matplotlib scipy
````

2. Запустите скрипт для задания 1:

```bash
python task1.py
```

3. Запустите скрипт для задания 2:

```bash
python task2.py
```

4. Для компиляции отчёта используйте `pdflatex`:

```bash
pdflatex report.tex
```

## Основные результаты

* В задании 1 выявлено, что мощность двигателя статистически значимо влияет на цену автомобиля, а расход топлива — нет. Остатки модели не являются нормально распределёнными.
* В задании 2 проведён ANOVA тест, показавший наличие статистически значимых различий в средних значениях площади чашелистика и лепестка у разных подвидов ириса.
