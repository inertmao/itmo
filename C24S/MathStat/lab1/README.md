# Лабораторная работа 1: Анализ набора данных о цветках ириса

## Описание

В данной лабораторной работе проводится анализ классического датасета **Iris** с помощью Python и популярных библиотек для анализа данных и визуализации. Скрипт рассчитывает статистики, строит графики, а также визуализирует распределения площадей чашелистиков и лепестков для различных видов ириса.

## Описание лабораторной работы

**Цель:**  
Изучить базовые методы анализа данных, рассчитать статистические характеристики и визуализировать распределения площадей чашелистиков и лепестков у ирисов разных видов.

**Выполняемые шаги:**
1. Загрузка и подготовка данных.
2. Расчёт новых признаков (площади лепестков и чашелистиков, суммарная площадь).
3. Расчёт частоты встречаемости видов.
4. Получение основных статистик по всей выборке и по видам.
5. Визуализация данных с помощью различных графиков.

## Как написать и запустить код

1. Перейдите по [ссылке на репозиторий](https://github.com/inertmao/itmo/blob/main/C24S/MathStat/lab1/1zadananie%20/index.py).
2. Скачайте файл скрипта.
3. Убедитесь, что в папке рядом с кодом находится файл `iris.csv`.
4. Откройте терминал/командную строку, перейдите в папку с файлом и выполните:
   ```bash
   python index.py
   ```
5. После выполнения появятся пять графиков (PNG/JPEG) и напечатаются результаты анализа в консоли.
