## 🧾 Описание работы скрипта

1. Загружает `iris.csv` и переименовывает колонки для удобства.
2. Вычисляет площади:

   * чашелистика (sepal\_area)
   * лепестка (petal\_area)
   * суммарную площадь (total\_area)
3. Подсчитывает количество экземпляров каждого вида.
4. Выводит статистику (общую и по видам):

   * Среднее
   * Дисперсия
   * Медиана
   * Квантиль (2/5)
5. Строит и сохраняет пять графиков:

   * `ecdf_all.png`
   * `ecdf_by_species.png`
   * `hist_all.png`
   * `hist_by_species.png`
   * `boxplot_by_species.png`
