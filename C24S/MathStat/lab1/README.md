# 📊 Лабораторная работа 1  
**Предмет**: Математическая статистика  
**Тема**: Анализ данных по длинам и ширинам лепестков и чашелистиков ирисов  

---

## 📌 Цель работы
Рассчитать статистические характеристики и визуализировать данные из набора `iris.csv`. Построить графики: гистограммы, ECDF (эмпирические функции распределения), boxplot.

---

## 🧾 Что делает программа

1. Загружает данные `iris.csv` и переименовывает колонки.
2. Вычисляет площадь чашелистика, лепестка и их сумму.
3. Подсчитывает количество экземпляров каждого вида.
4. Выводит общую и групповую (по видам) статистику:
   - Среднее
   - Дисперсия
   - Медиана
   - Квантиль 2/5
5. Строит и сохраняет 5 графиков:
   - `ecdf_all.png` — ECDF всей выборки
   - `ecdf_by_species.png` — ECDF по видам
   - `hist_all.png` — гистограмма всей выборки
   - `hist_by_species.png` — гистограмма по видам
   - `boxplot_by_species.png` — boxplot по видам

---

## 🛠 Как запустить

1. Установи зависимости:

```

pip install pandas matplotlib seaborn statsmodels

```

2. Убедись, что рядом с `.py`-файлом лежит `iris.csv`.

3. Запусти скрипт:

```

python lab1.py

```
