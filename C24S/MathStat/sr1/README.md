
# Отчет по самостоятельной работе 1  
## Медианные зарплаты и кредитные риски
<img alt="Я воин Дракона!" src="https://github.com/inertmao/itmo/blob/main/.docx/itmo6.gif">

В этом проекте реализованы решения двух задач по математической статистике:

---

### Задача 1: Зарплаты

- Рассчитаны описательные статистики по выборке медианных зарплат регионов.
- Построен вариационный ряд.
- Выполнена оценка параметров логнормального распределения методом моментов.
- Найдена информация Фишера, теоретическая MSE и доверительный интервал для параметра \(a\).
- Построены гистограмма и эмпирическая функция распределения.

---

### Задача 2: Кредитные Риски

- Рассмотрено распределение Лапласа.
- Проанализирована статистика \( |\bar{X}| \) как оценка параметра \(1/\beta\).
- Проверена смещённость, состоятельность и асимптотическая нормальность статистики.
- Найдена формула для асимптотической дисперсии и построен доверительный интервал.
- Обсуждены вопросы достаточности и R-эффективности оценки.

---

### Используемый код

- Скрипты на Python вычисляют все необходимые статистики, строят графики и доверительные интервалы.
- Код оформлен в виде простых скриптов для наглядности и удобства запуска.
