## Задание 1: Доверительный интервал для разности средних
Программа `task1.py` генерирует две выборки из нормальных распределений, вычисляет доверительный интервал для разности средних и визуализирует результаты.

### Параметры:
- `mu1 = 2`, `mu2 = 1`
- `var1 = 1`, `var2 = 0.5`
- Объемы выборок: `n = 25` и `n = 10000`
- Количество симуляций: `1000`

### Запуск:
```bash
python task1.py
```

### Вывод:
1. График `task1_plot.png` с 1000 доверительными интервалами:
   - Зелёные линии: интервалы, содержащие истинное значение τ = 1
   - Красные линии: интервалы, не содержащие истинное значение
   - Синяя пунктирная линия: истинное значение параметра
2. В консоль выводятся:
   - Доля покрытия для n=25
   - Доля покрытия для n=10000
   - Средняя ширина интервалов

### Пример вывода:
```
Задание 1:
Для n = 25: доля покрытия = 0.9400
Для n = 10000: доля покрытия = 0.9550
```
