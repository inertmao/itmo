# Лабораторная работа 3 — Статистический анализ цен на недвижимость

Репозиторий содержит код и результаты выполнения лабораторной работы по математической статистике, посвящённой анализу данных о ценах на недвижимость.

---

## Задачи работы

1. Проверка гипотезы о распределении цены (нормальность) с помощью критерия Колмогорова-Смирнова.
2. Сравнение распределений цены для старого и нового жилого фонда (порог возраста — 30 лет) с помощью критерия однородности Колмогорова-Смирнова.
3. Проверка зависимости цены от жилой площади — вычисление коэффициента корреляции Пирсона и проверка значимости.

---

## Используемые библиотеки

- `pandas` — для работы с данными
- `numpy` — для численных вычислений
- `matplotlib` — для построения графиков
- `scipy` — для статистических тестов

---

## Файлы репозитория

- `analysis.py` — основной скрипт с кодом анализа (проведение тестов, построение графиков)
- `kc_house_data.csv` — исходные данные о недвижимости
- `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg` — графики и результаты анализа
- `report.tex` — отчёт в формате LaTeX с оформлением результатов
