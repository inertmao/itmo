# 2 лаба по Выч мату... 


Данный репозиторий содержит программу для решения нелинейных уравнений и систем нелинейных уравнений тремя численными методами:

* Метод секущих
* Метод Ньютона
* Метод простой итерации

В рамках лабораторной работы № 2 по дисциплине «Вычислительная математика» реализованы следующие возможности:

* Выбор одного из трёх заранее заданных уравнений:

  1. $x^3 + 2x - 5 = 0$
  2. $\cos(x) - x = 0$
  3. $x^4 - 3x + 1 = 0$
* Решение выбранного уравнения с точностью $\varepsilon$ на указанном интервале $[a,\,b]$.
* Выбор метода решения (секущие, Ньютона, итерации).
* Ввод исходных данных (границы и погрешность) с клавиатуры или из файла.
* Проверка наличия ровно одного корня на указанном отрезке.
* Вывод результата (корень, значение функции в корне, число итераций) на экран или запись в файл.
* Построение графика функции с отмеченным найденным корнем.
* Решение одной из двух систем нелинейных уравнений методом Ньютона:
  1\.

  $$
  \begin{cases}
    x^2 + y^2 = 25,\\
    x^2 - y = 5;
  \end{cases}
  $$

  2.

  $$
  \begin{cases}
    e^x + y = 4,\\
    x + \sin(y) = 1.
  \end{cases}
  $$
* Ввод начального приближения и погрешности для системы.
* Вывод решения системы и истории погрешностей итераций.
* Построение контурного графика системы с отмеченным решением.

## Структура репозитория

```
Lab-2/
├── main.py              # Основной скрипт программы
├── helpers.py           # Вспомогательные функции (численные методы, чтение/запись, графики)
├── requirements.txt     # Список зависимостей Python
├── README.md            # Инструкция по работе с проектом
└── examples/            # Папка с примерами входных файлов и графиков
    ├── input1.txt
    ├── input2.txt
    ├── fig_function.png
    └── fig_system.png
```

* **main.py** — запускает главное меню, обрабатывает пользовательский ввод и вызывает численные методы.
* **helpers.py** — содержит реализацию:

  * Чтения/записи данных
  * Проверки наличия корня на отрезке
  * Метод секущих, метод Ньютона, метод итераций для одиночного уравнения
  * Метод Ньютона для системы
  * Функции построения графиков (Matplotlib)
* **requirements.txt** — перечисляет внешние библиотеки (sympy, numpy, matplotlib).
* **examples/** — примеры данных для тестирования и сохранённые изображения графиков.

  * `numpy`

Чтобы установить все зависимости, выполните:


## Запуск программы

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/inertmao/itmo/tree/main/C24S/2-compMath/Lab-2.git
   cd Lab-2
   ```

2. Убедитесь, что установлены зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустите `main.py`:

   ```bash
   python main.py
   ```

4. При запуске вы увидите главное меню:

   ```
   1) Решение одного уравнения
   2) Решение системы
   q) Выход
   Ваш выбор: 
   ```

5. Введите `1`, чтобы решить одно уравнение, или `2`, чтобы решить систему, либо `q` для выхода.

---

### Решение одного уравнения

1. Выбор уравнения:

   ```
   Выберите одно из трёх уравнений:
    1) x³ + 2·x − 5
    2) cos(x) − x
    3) x⁴ − 3·x + 1
   1..3: 
   ```

   Введите `1`, `2` или `3`.

2. Ввод исходных данных:

   ```
   1) Ввести a, b, ε с клавиатуры
   2) Считать из файла
   Ваш выбор: 
   ```

   * **Клавиатура**: программа запросит три значения:

     ```
     a = 
     b = 
     ε = 
     ```
   * **Файл**: введите имя файла (например, `input1.txt`), в котором три числа записаны либо в одну строку через пробел, либо в три строки.

3. Указание метода:

   ```
   Выберите метод:
    1) Секущие
    2) Ньютон
    3) Итерации
   1..3: 
   ```

   Введите `1`, `2` или `3`.

4. Способ вывода результата:

   ```
    1) Показать результат
    2) Записать в файл
   1 или 2: 
   ```

   * На экран (`1`)
   * В файл: введите имя файла для записи (`2`)

5. После этого будет напечатан корень, значение функции и число итераций. Автоматически строится график функции на заданном отрезке с отмеченным найденным корнем. Программа ждёт, пока вы закроете окно с графиком.

---

### Решение системы нелинейных уравнений

1. Выбор системы:

   ```
   Выберите систему:
    1) x² + y² = 25; x² − y = 5
    2) eˣ + y = 4; x + sin(y) = 1
   1 или 2: 
   ```

   Введите `1` или `2`.

2. Ввод начального приближения:

   ```
   x₀ = 
   y₀ = 
   ```

   Программа ждет два числа: начальные $x_0$ и $y_0$.

3. После расчёта методом Ньютона программа выведет:

   ```
   Решение: [x, y], Итераций: N
   Погрешности:
   [Δx₁, Δy₁]
   [Δx₂, Δy₂]
   ...
   ```

   Затем будет построен контурный график системы на окрестности полученного решения с отмеченной точкой.

## Критерии успешности

* Программа корректно определяет, есть ли ровно один корень на выбранном отрезке.
* Каждая итерационная процедура завершается при достижении указанной точности $\varepsilon$.
* Вывод результатов соответствует формату (корень, значение функции, число итераций).
* Строится график функции (или контур системы) с отмеченным решением.
