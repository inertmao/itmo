# README

## Назначение программы

Программа считывает 32‑битное целое число из памяти по адресу `0x80`, проходит по всем 32 его битам (от младшего к старшему) и **считает количество нулевых битов**.  
Результат записывается в память по адресу `0x84`, после чего выполнение останавливается.

Формально:

```
count_zero(n) = количество позиций i ∈ [0..31], где (n >> i) & 1 == 0
```

---

## Краткая схема работы

1. Прочитать число `n` из `0x80`.
2. Вызвать подпрограмму `count_zero`, которая:
   - сохраняет `n` в рабочую переменную `a`,
   - инициализирует счётчик нулей `cnt = 0`,
   - запускает цикл из 32 итераций,
   - на каждой итерации проверяет младший бит `a`:
     - если бит **нулевой**, увеличить `cnt`,
     - сдвинуть `a` вправо на 1 (убрать уже проверенный бит).
3. Сохранить `cnt` по адресу `0x84`.
4. Остановиться.

---

## Исходный код (ассемблероподобный язык стековой машины)

```asm
_start:
  @p 0x80        
  count_zero     
  !p 0x84        
  halt

count_zero:
  a!             
  lit 0          
  lit 31         
  >r

L:
  a              
  lit 1
  and            
  if INC         

CONT:
  a             
  2/             
  a!             

  next L         

  ;              

INC:
  lit 1
  +              
  CONT ;        
```

## Семантика используемых инструкций (принятая в этом README)

- `@p addr` — загрузить из памяти по адресу `addr` значение и положить на стек.
- `!p addr` — взять верх стека и сохранить в память по адресу `addr`.
- `lit x` — положить литерал `x` на стек.
- `a` — положить текущее значение регистра/ячейки `a` на стек.
- `a!` — снять верх стека и записать его в регистр/ячейку `a`.
- `and` — побитовое И над двумя верхними элементами стека.
- `2/` — целочисленное деление на 2 (логический сдвиг вправо на 1 для неотрицательных чисел).
- `>r` — переложить верх стека в стек возврата (R‑stack).
- `next L` — декрементировать счётчик цикла в стеке возврата; если он не отрицателен — переход к метке `L`.
- `if LABEL` — **переход к `LABEL`, если верх стека равен 0** (ветвление по нулевому флагу); при этом флаг со стека снимается.
- `;` — возврат из подпрограммы.
- `halt` — остановка.

> Примечание: Поведение `if` может отличаться в других реализациях. Для соответствия логике подсчёта **нулевых** битов и проверочным примерам ниже здесь используется семантика «прыжок, если флаг == 0».

## Постатейный разбор

### Точка входа `_start`

```asm
_start:
  @p 0x80        ; 1) взять n из памяти 0x80 -> в стек
  count_zero     ; 2) вызвать подсчёт нулей (результат останется на стеке)
  !p 0x84        ; 3) сохранить результат в память 0x84
  halt           ; 4) остановить выполнение
```

### Подпрограмма `count_zero`

Инициализация:

```asm
count_zero:
  a!             ; забрать n из стека и сохранить в рабочую переменную a
  lit 0          ; cnt = 0 (счётчик нулей) — лежит на стеке
  lit 31         ; подготовить 31 как "остаток" итераций
  >r             ; перенести 31 в стек возврата -> вместе с неявным счётчиком даст 32 итерации
```

Цикл по битам:

```asm
L:
  a              ; положить a на стек (вместе с cnt уже внизу стека)
  lit 1
  and            ; (a & 1) -> 0 если младший бит нулевой, 1 если единичный
  if INC         ; если 0, перейти к INC (увеличить счётчик нулей)
```

Если младший бит был **1**, перехода не происходит — мы попадаем на `CONT`, счётчик не меняется.  
Если младший бит был **0**, выполняется `INC` (см. ниже), где счётчик увеличивается на 1, затем управление также переходит на `CONT`.

Продолжение цикла:

```asm
CONT:
  a              ; снова положить a
  2/             ; логический сдвиг a вправо на 1 (убрать проверенный бит)
  a!             ; сохранить обновлённое a

  next L         ; уменьшить счётчик итераций и при необходимости повторить
                 ; после 32 итераций управление дойдёт до ';' (возврат)
  ;              
```

Инкремент счётчика нулей:

```asm
INC:
  lit 1          ; подготовить +1
  +
  CONT ;         ; увеличить cnt и продолжить цикл
```

Итог: на стеке остаётся `cnt` — число нулевых битов.

## Эквивалент на Python

```python
def count_zero(n: int) -> int:
    """Count the number of zeros in the 32-bit representation"""
    count = 0
    for _ in range(32):       # проверяем все 32 бита
        count += 0 if n & 1 else 1  # +1, если младший бит == 0
        n >>= 1               # сдвигаем число вправо
        # если нужны ровно 32 бита для отрицательных чисел: n &= 0x7FFFFFFF после сдвига и т.п.
    return count


# Проверочные примеры:
assert count_zero(5) == 30      # 000...0101 → два '1', значит 30 нулей
assert count_zero(7) == 29      # 000...0111 → три '1', значит 29 нулей
assert count_zero(247923789) == 19
```

## Пошаговые примеры

### Число `5` (0b…0101)

32‑битное представление:

```
00000000 00000000 00000000 00000101
```

Первые итерации:

| Итерация | Биты (младшие справа) | Младший бит | Действие          | Счётчик нулей |
|:--------:|:----------------------|:-----------:|:------------------|:-------------:|
| 1        | …0101                 | 1           | не увеличивать    | 0             |
| 2        | …0010                 | 0           | cnt ← cnt + 1     | 1             |
| 3        | …0001                 | 1           | не увеличивать    | 1             |
| 4        | …0000                 | 0           | cnt ← cnt + 1     | 2             |
| 5–32     | все 0                 | 0           | +1 на каждой      | 30            |

Итого: `count_zero(5) = 30`.

### Число `7` (0b…0111)

```
00000000 00000000 00000000 00000111
```

| Итерация | Биты (младшие справа) | Младший бит | Действие          | Счётчик нулей |
|:--------:|:----------------------|:-----------:|:------------------|:-------------:|
| 1        | …0111                 | 1           | не увеличивать    | 0             |
| 2        | …0011                 | 1           | не увеличивать    | 0             |
| 3        | …0001                 | 1           | не увеличивать    | 0             |
| 4        | …0000                 | 0           | cnt ← cnt + 1     | 1             |
| 5–32     | все 0                 | 0           | +1 на каждой      | 29            |

Итого: `count_zero(7) = 29`.

## Важные замечания

- **Разрядность.** Алгоритм рассчитан на 32 бита. Для 64‑битной версии просто проходите 64 итерации.
- **Отрицательные числа.** Если на вашей машине `2/` реализован как арифметический сдвиг (знаковый), используйте неотрицательные `n` или перед циклом маскируйте: `n &= 0xFFFFFFFF`.  
  Для чистого логического сдвига в знаковых типах можно применить маску после каждой итерации.
- **Связь с popcount.** Количество нулей = `32 − popcount(n)`, где `popcount(n)` — число единичных битов.

- Вход: значение `n` в памяти `0x80`.
- Выход: количество нулевых битов `cnt` записано в память `0x84`.
- Завершение: `halt`.
