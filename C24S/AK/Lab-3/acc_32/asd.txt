Шаги алгоритма
Чтение входа: из MMIO по адресу 0x80 берётся число n и сохраняется в переменную n.
Проверка области определения:
Если n < 1 → сразу вернуть -1 (записать 0xFFFFFFFF в 0x84).
Если n == 1 → вернуть 0 (1 не простое).
Если n == 2 → вернуть 1 (2 простое).
Быстрая фильтрация чётных:
Если n % 2 == 0 (и это не 2) → вернуть 0 (составное).
Основной цикл (суть):
Стартуем с нечётного делителя i = 3 и идём только по нечётным: 3, 5, 7, …
Считаем i*i - n. Если i*i > n ⇒ делителей не нашлось до √n ⇒ n простое → вернуть 1.
Иначе проверяем n % i. Если n % i == 0 ⇒ найден делитель ⇒ составное → вернуть 0.
Иначе i += 2 и повторяем.
Запись результата:
В MMIO по 0x84 пишется 1 (простое), 0 (составное) или -1 (для n < 1). Затем halt.
Почему это корректно
Если у числа есть нетривиальный делитель, хотя бы один будет ≤ √n. Поэтому достаточно перебирать до условия i*i > n.
Пропускаем чётные делители (после проверки чётности n) — экономит время.

Мини-прогоны в голове

n = -12 → n < 1 ⇒ пишем -1 в 0x84.

n = 5 → нечётное, не делится на 2; i=3: 3*3=9 > 5 ⇒ делителей ≤ √5 нет ⇒ пишем 1.

n = 9 → нечётное; i=3: 9 % 3 = 0 ⇒ найден делитель ⇒ пишем 0.

Сложность

В худшем случае ~½·√n проверок (только нечётные). Время — O(√n), память — несколько слов.

Технические детали реализации (почему всё не ломается)

Ввод/вывод — через MMIO: читать по 0x80, писать по 0x84.

.org 0x100 уводит код подальше от области IO, чтобы запись в 0x84 не перетёрла инструкции.

Ветвления beqz/bgt/ble используются на значении в аккумуляторе: перед веткой код всегда кладёт нужное выражение (например, i*i - n) в ACC и проверяет знак/ноль.



В чём суть задания (в 2 фразы)

Программа на acc32 читает 32-битный вход из адреса 0x80, проверяет, является ли число простым, и пишет ответ в адрес 0x84: 1 — простое, 0 — составное, -1 (0xFFFFFFFF) — если n < 1.




Алгоритм: быстрые случаи (n<1, 1, 2, чётность), затем перебор нечётных делителей i=3,5,7,… до условия i*i > n.

.data                          ; секция данных (переменные и константы)

n:      .word 0x0              ; переменная для входного числа n (32 бита)
i:      .word 0x0              ; счётчик-делитель i

zero:   .word 0x0              ; константа 0
one:    .word 0x1              ; константа 1
two:    .word 0x2              ; константа 2
three:  .word 0x3              ; константа 3 (первый нечётный делитель)
mone:   .word 0xffffffff       ; константа -1 (0xFFFFFFFF в two’s complement)

.org 0x100                     ; сдвиг кода подальше от MMIO (0x80..0x84), чтобы не перетирать инструкции

.text                          ; секция кода
_start:                        ; точка входа программы
    load_addr 0x80             ; ACC ← *0x80: читаем вход n из MMIO
    store_addr n               ; n ← ACC: сохраняем вход в переменную n

    load_addr n                ; ACC ← n
    sub one                    ; ACC ← n - 1
    ble domain_error           ; если ACC < 0 (n < 1) → перейти к domain_error и вернуть -1
    beqz not_prime             ; если ACC == 0 (n == 1) → перейти к not_prime и вернуть 0

    load_addr n                ; ACC ← n
    sub two                    ; ACC ← n - 2
    beqz prime                 ; если ACC == 0 (n == 2) → простое → перейти к prime

    load_addr n                ; ACC ← n
    rem two                    ; ACC ← n % 2
    beqz not_prime             ; если ACC == 0 (n чётное и >2) → составное → not_prime

    load_addr three            ; ACC ← 3
    store_addr i               ; i ← 3: старт перебора нечётных делителей

loop:
    load_addr i                ; ACC ← i
    mul i                      ; ACC ← i * i
    sub n                      ; ACC ← i*i - n
    bgt prime                  ; если ACC > 0 (i*i > n) → делителей не нашли → простое → prime

    load_addr n                ; ACC ← n
    rem i                      ; ACC ← n % i
    beqz not_prime             ; если ACC == 0 → нашли делитель i → составное → not_prime

    load_addr i                ; ACC ← i
    add two                    ; ACC ← i + 2
    store_addr i               ; i ← i + 2: следующий нечётный делитель
    jmp loop                   ; повторить цикл

prime:
    load_addr one              ; ACC ← 1 (флаг «простое»)
    store_addr 0x84            ; *0x84 ← ACC: записать результат в MMIO (выход)
    halt                       ; останов

not_prime:
    load_addr zero             ; ACC ← 0 (флаг «составное»)
    store_addr 0x84            ; *0x84 ← ACC
    halt                       ; останов

domain_error:
    load_addr mone             ; ACC ← -1 (для n < 1 по требованию задания)
    store_addr 0x84            ; *0x84 ← ACC
    halt                       ; останов




loop:
    load_addr i        ; acc = i
    mul i              ; acc = i*i
    sub n              ; acc = i*i - n
    bgt prime          ; если i*i > n → делителей нет → простое

    load_addr n        ; acc = n
    rem i              ; acc = n % i
    beqz not_prime     ; если остаток 0 → нашли делитель → составное

    load_addr i        ; acc = i
    add two            ; acc = i + 2
    store_addr i       ; i = i + 2 (следующий нечётный делитель)
    jmp loop           ; повторяем
