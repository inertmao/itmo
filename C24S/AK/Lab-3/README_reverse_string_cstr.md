# README — `reverse_string_cstr` (RISC-V, двухпроходный, рекурсивный реверс C‑префикса)

Этот документ описывает работу программы на RISC‑V, которая читает строку из потока ввода, **реверсирует только её C‑префикс** (участок от начала до первого байта `NUL` включительно не проходит в вывод, вывод останавливается на `NUL`), а затем печатает результат до первого `NUL`. Программа делает два прохода по входу, использует буфер фиксированного размера и рекурсивную подпрограмму для реверса диапазона.

> Ключевая идея: реверсируются только байты диапазона `Buf[0 .. c_len-1]`, где `c_len` — позиция первого `NUL` в прочитанной строке (если `NUL` не встретен до `'\n'`, берётся вся длина). Печать выполняется **до первого `NUL`** — это и есть C‑строка (C‑префикс).

---

## Память (секция `.data`)

| Метка        | Тип   | Значение / смысл                                       |
|--------------|-------|---------------------------------------------------------|
| `Buf`        | `.byte` × 0x20 | Рабочий буфер на **32 байта** (инициализирован символами `'_'`) |
| `BufSize`    | `.word` | `0x20` (32) — размер буфера в байтах                  |
| `InStopChar` | `.word` | `'\n'` — символ завершения ввода (конец линии)        |
| `OvErr`      | `.word` | `0xCCCCCCCC` — код переполнения для вывода            |
| `Mask`       | `.word` | `0x7F` — маска ASCII (оставляет 7 младших бит)       |
| `InputAddr`  | `.word` | `0x80` — адрес memory‑mapped входа (чтение слова)     |
| `OutputAddr` | `.word` | `0x84` — адрес memory‑mapped выхода (запись слова)    |

> Замечание: чтение/запись идут по **одним и тем же адресам** (`lw 0(a0)` и `sw 0(s0)`), без инкремента адреса — предполагается периферия‑поток: каждый `lw` выдаёт **следующий** символ входа, каждый `sw` печатает **один** символ на выход.

---

## Точка входа и настройка стека

```asm
.org 0x90
_start:
    ; безопасный стек (валидно при memory_size 0x500 и 0x1000)
    lui     sp,0
    addi    sp,sp,1024
    addi    sp,sp,-4
```

- Стек размещается безопасно относительно нулевой страницы (примерно на 1 KiB от начала), затем выравнивается.
- Это важно для глубины рекурсии в подпрограмме `rev_range` (см. далее).

## Инициализация регистров и констант

```asm
    ; s0 = addr(OUTPUT)
    lui     t0,0
    addi    t0,t0,52
    lw      s0,0(t0)

    ; a0 = addr(INPUT)
    lui     t0,0
    addi    t0,t0,48
    lw      a0,0(t0)

    ; s8 = 0x7f (маска ASCII), s6 = '\n'
    lui     t1,0
    addi    t1,t1,44
    lw      s8,0(t1)
    lui     t1,0
    addi    t1,t1,36
    lw      s6,0(t1)

    ; a3 = &Buf, a2 = BufSize
    lui     t1,0
    addi    a3,t1,0
    lui     t1,0
    addi    t1,t1,32
    lw      a2,0(t1)
```

- `s0` ← `OutputAddr` (адрес устройства вывода).  
- `a0` ← `InputAddr` (адрес устройства ввода).  
- `s8` ← `Mask` (`0x7F`) для нормализации входа к 7‑битному ASCII.  
- `s6` ← `InStopChar` (`'\n'`) — символ завершения ввода строки.  
- `a3` ← `&Buf` (указатель на начало буфера).  
- `a2` ← `BufSize` (ёмкость буфера, байт).

## PASS 1: чтение строки в буфер, вычисление `total` и `c_len`

```asm
    mv      a1,a3              ; ptr записи в буфер
    mv      s1,zero            ; total: сколько байт прочитано (до '\n')
    addi    s5,zero,-1         ; c_len = -1 (ещё не находили NUL)

read_loop:
    lw      t0,0(a0)           ; прочитать следующий символ из ввода
    and     t0,t0,s8           ; нормализовать к 7-бит ASCII
    beq     t0,s6,read_done    ; если '\n' -> конец ввода строки

    sb      t0,0(a1)           ; записать байт в буфер
    addi    a1,a1,1            ; сдвинуть указатель записи
    addi    s1,s1,1            ; total++

    ; зафиксировать первую позицию NUL как c_len
    bnez    t0,skip_zero_mark  ; если байт != 0, пропустить
    addi    t2,s5,1            ; t2=0 только если s5==-1 (ещё не фиксировали)
    bnez    t2,skip_zero_mark
    addi    s5,s1,-1           ; c_len = текущий индекс (s1-1)
skip_zero_mark:

    ; overflow, если достигли BufSize до '\n'
    beq     s1,a2,overflow
    j       read_loop
```

- `total (s1)` — длина прочитанной линии **до** символа `'\n'`.  
- `c_len (s5)` — **первая позиция `NUL` (0x00)** в прочитанных данных; если `NUL` не встретился, будет выставлен в конце равным `total`.

Завершение чтения и пост‑обработка:

```asm
read_done:
    ; если NUL не встречали — c_len = total
    addi    t2,s5,1
    bzez    t2,have_clen       ; псевдо: "если s5 == -1" — см. пояснение ниже
    mv      s5,s1
have_clen:

    ; общий «хвостовой» NUL по всей прочитанной линии
    add     t0,a3,s1
    sb      zero,0(t0)         ; Buf[total] = 0 (страховочный завершающий NUL)

    ; c_len должен умещаться в 31 байт
    addi    t2,a2,-1           ; BufSize-1
    bgtu    s5,t2,overflow     ; если c_len > 31 -> overflow
```
> В оригинальном коде проверка сделана парой инструкций `addi t2,s5,1` / `bnez t2,have_clen`. Здесь для краткости отмечено как «если s5 == -1, то s5 := total».

## PASS 2: реверс **только C‑префикса** `[0 .. c_len-1]`

```asm
    beq     s5,zero,set_c_nul  ; если c_len==0, реверс не требуется
    mv      a4,a3              ; left_ptr = &Buf[0]
    add     a5,a3,s5           ; right_ptr = &Buf[c_len]
    addi    a5,a5,-1           ; -> &Buf[c_len-1]
    jal     ra,rev_range
```

После реверса выставляется завершающий `NUL` именно в конце C‑префикса:

```asm
set_c_nul:
    add     t2,a3,s5
    sb      zero,0(t2)         ; Buf[c_len] = 0
```

Тем самым `Buf` становится корректной C‑строкой из **перевёрнутого префикса**.

## Печать (до первого `NUL`)

```asm
    mv      t2,a3
print_loop:
    lw      t3,0(t2)           ; взять следующий байт из буфера
    and     t3,t3,s8
    beq     t3,zero,finish     ; остановиться на NUL
    sw      t3,0(s0)           ; вывести байт
    addi    t2,t2,1            ; к следующему байту
    j       print_loop

finish:
    halt
```

- Идёт посимвольный вывод до первого нулевого байта — классическая печать C‑строки.  
- Используется маска `0x7F` для соответствия 7‑битному ASCII.

## Рекурсивный реверс диапазона `rev_range`

```asm
; rev_range(left_ptr=a4, right_ptr=a5): реверс на месте
rev_range:
    addi    sp,sp,-8
    sw      ra,4(sp)

    bgtu    a4,a5,rr_exit      ; указатели пересеклись — конец
    beq     a4,a5,rr_exit      ; встретились в центре — конец

    lw      t0,0(a4)
    and     t0,t0,s8
    lw      t1,0(a5)
    and     t1,t1,s8
    sb      t1,0(a4)           ; обмен байтов
    sb      t0,0(a5)

    addi    a4,a4,1            ; шаг внутрь
    addi    a5,a5,-1
    jal     ra,rev_range       ; рекурсивный шаг

rr_exit:
    lw      ra,4(sp)
    addi    sp,sp,8
    jr      ra
```

- Обменивает парные символы слева/справа и рекурсивно сужает диапазон.  
- **Глубина рекурсии ≈ ⌈c_len/2⌉**, при `c_len ≤ 31` — максимум 16 кадров. При 8 байт на кадр → ~128 байт стека — запас обеспечен настройкой стека в `_start`.

## Обработка переполнения буфера

```asm
overflow:
    lui     t1,0
    addi    t1,t1,40
    lw      t2,0(t1)           ; t2 = OvErr (0xCCCCCCCC)
    sw      t2,0(s0)           ; вывести код ошибки
    halt
```

Если до символа `'\n'` длина строки достигла `BufSize`, печатается `0xCCCCCCCC` и выполнение прекращается.

---

## Поведение на примерах

1. **Без нулевых байтов**: \
   Ввод: `hello\n` → `c_len = 5` → реверс `hello` → Буфер: `olleh\0` → Вывод: `olleh`

2. **С нулём внутри**: \
   Ввод: `ab\0cd\n` → `c_len = 2` → реверс только `ab` → Буфер: `ba\0cd\0` → Вывод останавливается на первом `\0` → `ba`

3. **Пустая строка**: \
   Ввод: `\n` → `total = 0`, `c_len = 0`, Буфер: `\0` → Вывод пустой

4. **Переполнение**: \
   Ввод: `A…A\n` (≥ 32 символов до `'\n'`) → печатается `0xCCCCCCCC`, `halt`.

> Все входные байты нормализуются через `& 0x7F`, т.е. старший бит отбрасывается (полезно для шумных / 8‑битных источников).

## Сопоставление регистров (основные)

| Регистр | Назначение                                  |
|--------:|----------------------------------------------|
| `sp`    | стек                                         |
| `ra`    | адрес возврата (в `rev_range`)               |
| `s0`    | адрес устройства вывода (`OutputAddr`)       |
| `a0`    | адрес устройства ввода (`InputAddr`)         |
| `a1`    | текущий указатель записи в `Buf`             |
| `a2`    | `BufSize`                                    |
| `a3`    | `&Buf`                                       |
| `a4`    | левый указатель (для `rev_range`)            |
| `a5`    | правый указатель (для `rev_range`)           |
| `s1`    | `total` — сколько байт прочитано до `'\n'`   |
| `s5`    | `c_len` — позиция первого `NUL` или `total`  |
| `s6`    | `InStopChar` (`'\n'`)                        |
| `s8`    | `Mask` (`0x7F`)                              |
| `t0..t3`| временные                                     |

## Псевдо‑C (упрощённо)

```c
// Устройство ввода/вывода: чтение/запись одного байта на каждый lw/sw
uint8_t in_read(void);   // lw 0(a0) & 0x7F
void out_write(uint8_t); // sw 0(s0)

char Buf[32]; // BufSize = 32

void reverse_string_cstr(void) {
    size_t total = 0;
    ssize_t c_len = -1;

    // PASS 1: чтение до '\n' или до переполнения
    for (;;) {
        uint8_t ch = in_read() & 0x7F;
        if (ch == '\n') break;
        if (total == sizeof(Buf)) overflow(); // печать 0xCCCCCCCC и halt
        Buf[total++] = ch;
        if (ch == 0 && c_len < 0) c_len = (ssize_t)total - 1;
    }

    if (c_len < 0) c_len = (ssize_t)total;
    Buf[total] = 0;               // общий хвостовой NUL
    if ((size_t)c_len > sizeof(Buf) - 1) overflow();

    // PASS 2: реверс только префикса [0..c_len-1]
    if (c_len > 0) {
        size_t L = 0, R = (size_t)c_len - 1;
        while (L < R) {
            uint8_t tmp = Buf[L];
            Buf[L] = Buf[R];
            Buf[R] = tmp;
            L++; R--;
        }
    }
    Buf[c_len] = 0;               // C-строка завершается на c_len

    // Печать до первого NUL
    for (size_t i = 0; ; i++) {
        uint8_t ch = Buf[i] & 0x7F;
        if (ch == 0) break;
        out_write(ch);
    }
}
```

## Сложность и ресурсы

- Время: `O(total + c_len)` (чтение + реверс префикса).  
- Память: фиксированный буфер `32` байта + стек. Глубина рекурсии ≤ `ceil(c_len/2)` → до ~16 кадров, ~128 байт при 8 байт/кадр.  
- Безопасность: защита от переполнения (ранний выход), принудительная завершающая нуль‑терминация.

---

## Важные детали и переносимость

- Модель ввода/вывода предполагает **потоковую периферию**: каждый `lw 0(a0)` даёт следующий байт, каждый `sw 0(s0)` печатает байт. Если порт другой, потребуется инкремент адресов или иной протокол.
- Инструкция `lw` и `sw` в примере работают с «байтом» из периферии через младшие биты регистра; далее он нормализуется маской `0x7F`. На реальном железе возможны требования к выравниванию/разрядности — учитывайте специфику MMIO.
- Буфер малый (`32` байта): строки длиннее 31 символа до `'\n'` вызовут `overflow`.
- Поддержка 8‑битных символов отсутствует умышленно (маска 7‑битного ASCII).

---

## Краткое резюме

Программа читает линию из потока, **находит C‑префикс до первого `NUL`**, реверсирует его (на месте, рекурсией), корректно завершает `NUL`‑ом и печатает результат до `NUL`. При переполнении печатает код ошибки `0xCCCCCCCC` и останавливается.
